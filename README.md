# 2048 — Android, Kotlin + Jetpack Compose

- Поле 4×4, свайпы или 4 кнопки-стрелки
- Одинаковые плитки сливаются (каждая — один раз за ход), после хода появляется новая 2 (90%) или 4 (10%)
- Счёт и **рекорд** сверху, рекорд сохраняется (SharedPreferences)
- «Победа» при плитке 2048 с выбором «Играть дальше», «Игра окончена» когда ходов нет
- Классические цвета плиток, анимация появления
- Логика отделена от UI (`Game2048.kt`), 7 unit-тестов
